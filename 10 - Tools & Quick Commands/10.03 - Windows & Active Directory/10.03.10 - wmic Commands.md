## Overview

`wmic` can be used to enumerate local host information, domain information, users, groups, computers, installed updates, AV products, files, and some remote management settings.

> [!note]
> `wmic` is deprecated on newer Windows versions, but it still appears frequently in labs, legacy systems, and exam-style environments.

---

# Host Enumeration

## OS Specifics

### Full OS Information

```cmd
wmic os LIST Full
```

Use the `caption` property to identify the OS name.

Example:

```cmd
wmic os get caption
```

---

## Computer System Information

```cmd
wmic computersystem LIST full
```

Useful for identifying:

```text
hostname
domain membership
manufacturer
model
system type
logged-on user
total physical memory
```

---

# Anti-Virus Enumeration

## List Installed AV Products

```cmd
wmic /namespace:\\root\securitycenter2 path antivirusproduct
```

Useful for identifying:

```text
installed AV
endpoint protection products
security product names
```

> [!tip]
> On servers or hardened systems, the `root\securitycenter2` namespace may not exist or may return no results.

# Directory Listing and File Search

## List Files in a Specific Directory

```cmd
wmic DATAFILE where "path='\\Users\\test\\Documents\\'" GET Name,readable,size
```

Returns:

```text
file name
readable status
file size
```

---

## Search for Files Containing “password”

```cmd
wmic DATAFILE where "drive='C:' AND Name like '%password%'" GET Name,readable,size /VALUE
```

Useful for finding files with names containing:

```text
password
```

Returned fields:

```text
Name
readable
size
```

> [!warning]
> Broad `DATAFILE` searches can be slow and noisy on large drives.

# Domain Enumeration

## Domain and Domain Controller Information

```cmd
wmic NTDOMAIN GET DomainControllerAddress,DomainName,Roles /VALUE
```

Useful for identifying:

```text
domain name

```

# Domain User Enumeration

## Query a Specific Domain User

```cmd
wmic /NAMESPACE:\\root\directory\ldap PATH ds_user where "ds_samaccountname='testAccount'" GET
```

Replace:

```text
testAccount
```

with the target username.

---

## List All Domain Users

```cmd
wmic /NAMESPACE:\\root\directory\ldap PATH ds_user GET ds_samaccountname
```

Useful for building:

```text
domain user lists
spray target lists
enumeration notes
```

---

# Domain Group Enumeration

## List All Domain Groups

```cmd
wmic /NAMESPACE:\\root\directory\ldap PATH ds_group GET ds_samaccountname
```

Useful for identifying:

```text
privileged groups
custom groups
department groups
application groups
```

---

## Members of a Domain Group

```cmd
wmic /NAMESPACE:\\root\directory\ldap PATH ds_group where "ds_samaccountname='Domain Admins'" Get ds_member /Value
```

Useful for enumerating members of:

```text
Domain Admins
Enterprise Admins
Administrators
Remote Management Users
Remote Desktop Users
Backup Operators
custom admin groups
```

---

## Domain Admins Group via win32_groupuser

```cmd
wmic path win32_groupuser where (groupcomponent="win32_group.name="domain admins",domain="YOURDOMAINHERE"")
```

Replace:

```text
YOURDOMAINHERE
```

with the target domain name.

> [!note]
> WMIC quoting can be fragile. If this command fails, re-check escaping and quote placement.

# Domain Computer Enumeration

## List All Domain Computers by SAM Account Name

```cmd
wmic /NAMESPACE:\\root\directory\ldap PATH ds_computer GET ds_samaccountname
```

Computer accounts usually appear with a trailing `$`.

Example:

```text
DC01$
WEB01$
CLIENT01$
```

---

## List All Domain Computers by DNS Hostname

```cmd
wmic /NAMESPACE:\\root\directory\ldap PATH ds_computer GET ds_dnshostname
```

Useful for building target lists such as:

```text
domain controllers
file servers
web servers
workstations
SQL servers
```

# Miscellaneous WMIC Commands

## Execute Local Command

```cmd
wmic process call create "cmd.exe /c calc.exe"
```

This creates a new process through WMI.

Example process:

```text
calc.exe
```

# Remote Desktop Management

## Enable Remote Desktop Locally

```cmd
wmic rdtoggle where AllowTSConnections="0" call SetAllowTSConnections "1"
```

Purpose:

```text
enable RDP connections on the local host
```

---

## Enable Remote Desktop on a Remote Host

```cmd
wmic /node:remotehost path Win32_TerminalServiceSetting where AllowTSConnections="0" call SetAllowTSConnections "1"
```

Replace:

```text
remotehost
```

with the target hostname or IP.

# Operator Workflow

## Host Enumeration Flow

```text
1. Identify OS and system details.
2. Check AV products.
3. Check installed updates.
4. Enumerate local users.
5. Search interesting paths.
6. Look for password-related files.
```

Commands:

```cmd
wmic os get caption
wmic computersystem LIST full
wmic /namespace:\\root\securitycenter2 path antivirusproduct
wmic qfe list brief
wmic USERACCOUNT Get Domain,Name,Sid
wmic DATAFILE where "drive='C:' AND Name like '%password%'" GET Name,readable,size /VALUE
```

---

## Domain Enumeration Flow

```text
1. Identify domain and DC information.
2. List domain users.
3. List domain groups.
4. Check privileged group membership.
5. List domain computers.
6. Build target and user lists for follow-up enumeration.
```

Commands:

```cmd
wmic NTDOMAIN GET DomainControllerAddress,DomainName,Roles /VALUE
wmic /NAMESPACE:\\root\directory\ldap PATH ds_user GET ds_samaccountname
wmic /NAMESPACE:\\root\directory\ldap PATH ds_group GET ds_samaccountname
wmic /NAMESPACE:\\root\directory\ldap PATH ds_group where "ds_samaccountname='Domain Admins'" Get ds_member /Value
wmic /NAMESPACE:\\root\directory\ldap PATH ds_computer GET ds_dnshostname
```

# If You Find X, Try Y

| Finding | Try Next |
|---|---|
| OS version | Check patch level with `wmic qfe list brief` |
| Missing updates | Research possible privilege escalation or exploit paths |
| AV product | Adjust testing expectations and note defensive tooling |
| Domain name / DC | Begin LDAP/domain enumeration |
| Domain users | Build user list for further checks |
| Domain groups | Identify privileged/custom groups |
| Domain Admins members | Mark as high-value users |
| Domain computers | Build host target list |
| Password-like filenames | Inspect readable files carefully |
| Local users | Check privilege level and reuse potential |
| RDP disabled | Enable only if authorised and appropriate |

# Troubleshooting

## WMIC Command Fails

Possible causes:

```text
wmic not installed
wmic deprecated or removed
insufficient permissions
WMI service issues
namespace does not exist
bad quoting
remote firewall blocks WMI
```

---

## LDAP Namespace Queries Fail

Possible causes:

```text
not domain joined
not authenticated to domain
cannot reach domain controller
LDAP/WMI provider issue
insufficient permissions
incorrect namespace path
```

Namespace used:

```cmd
/NAMESPACE:\\root\directory\ldap
```

---

## SecurityCenter2 Query Returns Nothing

Possible causes:

```text
namespace unavailable
server OS
AV not registered there
permissions issue
security product hides details
```

Command:

```cmd
wmic /namespace:\\root\securitycenter2 path antivirusproduct
```

---

## DATAFILE Search Is Slow

Reason:

```text
WMIC may search across many file records.
```

Prefer narrowing by:

```text
drive
path
filename pattern
```

Example:

```cmd
wmic DATAFILE where "path='\\Users\\test\\Documents\\'" GET Name,readable,size
```

# Defensive Notes

WMIC enumeration and management activity may generate:

```text
WMI process creation events
WMI queries
wmic.exe process execution
domain LDAP queries through WMI provider
remote WMI activity
RDP configuration changes
file system enumeration
```

Suspicious commands:

```cmd
wmic DATAFILE where "drive='C:' AND Name like '%password%'"
wmic process call create
wmic rdtoggle where AllowTSConnections="0" call SetAllowTSConnections "1"
wmic /node:remotehost
```

Possible controls:

```text
monitor wmic.exe usage
restrict WMI remote access
log process creation events
monitor RDP configuration changes
audit local admin rights
monitor broad file searches
restrict legacy tooling where possible
```
