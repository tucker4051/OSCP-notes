## Overview

**SharpView** is a .NET port of PowerView.

It supports many of the same concepts and functions as PowerView, but runs as a compiled executable instead of a PowerShell script.

This can be useful when:

```text
PowerShell usage is restricted
PowerShell logging is heavily monitored
PowerView import is blocked
a compiled .NET tool is preferred
```

> [!note]
> Evasion is not the focus here. SharpView is still an offensive tool and may be detected.

---

# Relationship to PowerView

PowerView:

```text
PowerShell script
```

SharpView:

```text
.NET executable
```

Both can enumerate similar Active Directory information.

Examples:

```text
users
groups
computers
SPNs
delegation settings
pre-authentication settings
domain information
LDAP filters
```

# Useful Fields

| Field | Why It Matters |
|---|---|
| `objectsid` | Full SID for the user |
| `useraccountcontrol` | Account flags |
| `lastlogon` | User activity |
| `lastlogontimestamp` | Replicated logon activity |
| `pwdlastset` | Password age |
| `badPasswordTime` | Recent failed auth activity |
| `badpwdcount` | Spray risk |
| `memberof` | Group-based access |
| `distinguishedname` | OU and domain location |
| `logoncount` | Account usage |

# Example Finding

Example user:

```text
forend
```

Example DN:

```text
CN=forend,OU=IT Admins,OU=IT,OU=HQ-NYC,OU=Employees,OU=Corp,DC=INLANEFREIGHT,DC=LOCAL
```

Interpretation:

```text
The user belongs to an IT-related OU.
The account may have useful access or be worth further review.
```

Example membership:

```text
VPN Users
Shared Calendar Read
Printer Access
File Share H Drive
File Share G Drive
```

Decision:

```text
If user has file share group memberships:
    inspect corresponding shares

If user is in IT-related OU:
    check permissions, sessions, and local admin rights
```

# SharpView Decision Points

```text
If PowerView is blocked:
    try SharpView

If you need user attributes:
    Get-DomainUser

If you need SPN users:
    use Get-DomainUser with SPN-related options

If you need pre-authentication targets:
    use PreauthNotRequired-related options

If you need specific properties:
    use -Properties where supported
```

---

# Practical Workflow

```text
1. Run method help.
2. Enumerate current or target user.
3. Review group memberships.
4. Review UAC flags.
5. Review SPN or pre-authentication indicators.
6. Correlate with PowerView, BloodHound, or manual checks.
```

# When SharpView Is Useful

Use SharpView when:

```text
PowerShell script import is blocked
you want PowerView-like functionality in executable form
you are testing from a Windows attack host
you need LDAP-based AD enumeration
```

---

# Key Takeaways

- SharpView is a .NET port of PowerView.
- It supports many PowerView-like enumeration functions.
- Use `-Help` with a method to discover supported arguments.
- It can enumerate detailed user attributes.
- It may be useful when PowerShell-based tooling is restricted.
- Findings should be correlated with PowerView, BloodHound, and manual checks.
